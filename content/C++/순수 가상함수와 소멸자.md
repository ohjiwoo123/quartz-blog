
## 순수 가상함수와 추상클래스 
클래스 중에서는 객체 생성을 목적으로 정의 되지 않은 클래스도 존재한다. 

```
Class Employee
{
private:
char name[100];

public
Employee(char *name) {....}
void ShowAYourName() const {....} // const 멤버 함수, 읽기만 가능
virtual int GetPay() const
{
return 0;
}
virtual void ShowSalaryInfo() const {}
};
```
Employee * emp = new Emplyoee("Lee Dong Sook") 
이러면 컴파일러에서 에러를 발견하지 못한다.
(아직 다른 멤버 함수들이 정의 되지 않음...)
`순수 가상함수 함수`란 함수의 몸체가 정의 되지 않은 함수를 의미한다. 

```
virtual int GetPay() const = 0;
virtual void ShowSalaryInfo() const = 0;
```
0을 대입하므로서 명시적으로 몸체를 정의하지 않았음을 컴파일러에게 알린다. 
이렇게 되면 잘못 된 객체 생성을 막을 수 있다.  
그리고 이렇듯 하나 이상의 멤버함수를 순수 가상함수로 선언한 클래스를 가리켜 `추상클래스`라고 부른다.  
이는 완전하지 않은, 그래서 객체 생성이 불가능한 클래스라는 의미를 지닌다.

### 가상 소멸자
항상 소멸자에는 웬만하면 virtual로 소멸자를 선언하는 것이 좋다.   
이유는 즉슨... 예를들어 
```
int main(void)
{
First *ptr = new Second("simple", "complex");
delete ptr;
return 0;
}
```
class가 First와 Second 가 있다고 가정했을 때, 이 경우 가상소멸자를 사용하지 않으면 First 객체의 소멸자만 불린다...  

소멸자를 쓰는 경우 상속 구조에서
```
Class First
{
public : 
virtual ~First()
};
Class Second : public First
{
public : 
virtual ~Second()
};
Clss Third : public Second
public : 
virtual ~Third()
```
3->2->1 순서로 소멸자가 호출 됨.
