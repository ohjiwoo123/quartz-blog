# STEP-3

프로그램을 다만들면 본인 서버에 도커로 올려보자   

Dockerfile을 만들고  
```
FROM python:3.9

WORKDIR /bugreport

COPY requirements.txt .

RUN pip install --no-cache-dir -r requirements.txt

COPY . .

CMD ["python", "bugreport.py"]

```

본인 서버에 도커 엔진 다운로드 후 
```
# 본인환경으로 requirements.txt 만들기  
pip freeze > requirements.txt
docker build -t my-python-app .
docker run -d -p 443:443 my-python-bot

# .env 파일에서 읽게 하려면 옵션을 넣어야함. 
sudo docker run -d -e BOT_TOKEN="bottoken" -e CHAT_ID="-123456" b-bot

소스코드에서 os.getenv -> os.environ 으로 변경 
token = os.environ["BOT_TOKEN"]
chat_id = int(os.environ["CHAT_ID"])

# 자동 restart 
sudo docker run -d \
  --name my-bot-container \
  --restart always \
  -e BOT_TOKEN="{BOT_TOKEN}" \
  -e CHAT_ID="{CHAT_ID}" \
  -e CHAT_ID2="{CHAT_ID2}" \
  m-bot


```
 
-d 옵션 = 데몬 (백그라운드)  
-rm 옵션 = 이미지 바로 지우는 옵션  


## 유용한 도커명령어 모음

```
# 컨테이너 확인 
sudo docker ps -a 
# 컨테이너 삭제
sudo docker rm 컨테이너ID

# 이미지 확인
sudo docker images 
# 이미지 삭제
sudo docker rmi images 

# 컨테이너 점검 (네트워크설정 등 확인)
sudo docker inspect 컨테이너ID

# 컨테이너 로그 확인 
sudo docker logs 컨테이너ID

```
