### CPU 코어 사용량
```
# 실시간 CPU 전체 코어 사용량 확인 
sar -P ALL 1 

# 3번 코어, 특정 날짜에 대한 CPU 코어 사용량 확인  
sar -P 3 -f /var/log/sa/sa30 -s '12:00:00' -e '12:03:00'

# 전체 데이터를 csv로 변환
sadf -d ./sa20 -- -P ALL | sed 's/;/,/g' > sa20.csv

# 특정 시간대의 데이터를 csv로 변환
sadf -d ./sa20 -- -s 17:00:00 -e 17:20:00 -P ALL | sed 's/;/,/g' > sa20_17_20.csv
```
### 메모리 사용량
```
# 일반 mem , total, used 등 보는 명령어
```

각 열의 의미 : 
1.Device
- nvme0n1: I/O 통계를 나타내는 장치 이름입니다. 여기서는 nvme0n1이라는 NVMe SSD 디스크.

2.r/s (read requests per second)
- 초당 읽기 요청 횟수.
0.00은 현재 이 디스크에서 초당 읽기 요청이 없다는 의미입니다.

3. w/s (write requests per second)
- 초당 쓰기 요청 횟수.
3.00은 초당 3번 쓰기 요청이 있다는 의미입니다.
rkB/s (read kilobytes per second)
초당 읽은 데이터의 양 (KB 단위).
0.00은 읽기 데이터 전송량이 없다는 의미입니다.
wkB/s (write kilobytes per second)
초당 쓴 데이터의 양 (KB 단위).
19.50은 초당 19.5 KB의 데이터를 쓴다는 의미입니다.

4. rrqm/s (read requests merged per second)
- 초당 병합된 읽기 요청의 수.
0.00은 병합된 읽기 요청이 없다는 의미입니다.

5. wrqm/s (write requests merged per second)
- 초당 병합된 쓰기 요청의 수.
0.00은 병합된 쓰기 요청이 없다는 의미입니다.

6. %rrqm (percent of read requests merged)
- 병합된 읽기 요청의 비율. rrqm/s / r/s * 100으로 계산.
0.00%는 읽기 요청 병합 비율이 없다는 의미입니다.
7. %wrqm (percent of write requests merged)
- 병합된 쓰기 요청의 비율. wrqm/s / w/s * 100으로 계산.
0.00%는 쓰기 요청 병합 비율이 없다는 의미입니다.
8. r_await (average read request wait time in ms)
- 읽기 요청 대기 시간의 평균 (밀리초 단위).
0.00은 읽기 요청의 대기 시간이 없거나 매우 빠르다는 의미입니다.
9. w_await (average write request wait time in ms)
- 쓰기 요청 대기 시간의 평균 (밀리초 단위).
1.00은 쓰기 요청을 처리하는 데 평균 1ms가 걸린다는 의미입니다.
10. aqu-sz (average queue size)
- 요청 대기열의 평균 크기. 디스크에 대기 중인 I/O 요청의 평균 개수.
0.00은 대기 중인 I/O 요청이 없다는 의미입니다.
11. rareq-sz (average read request size in KB)
- 평균 읽기 요청 크기 (KB 단위).
0.00은 읽기 요청 크기가 없다는 의미입니다.
12. wareq-sz (average write request size in KB)
- 평균 쓰기 요청 크기 (KB 단위).
6.50은 평균적으로 각 쓰기 요청이 6.5 KB 크기라는 의미입니다.
13. svctm (average service time in ms)
- I/O 요청을 처리하는 데 걸리는 평균 서비스 시간 (밀리초 단위).
1.00은 각 I/O 요청을 처리하는 데 평균 1ms가 걸린다는 의미입니다.
14. %util (disk utilization)
- 디스크의 사용률. 디스크가 얼마나 바쁜지 나타내는 비율 (0-100%).
0.30%는 디스크가 전체 시간 중 0.3%만 사용 중이라는 의미입니다.
