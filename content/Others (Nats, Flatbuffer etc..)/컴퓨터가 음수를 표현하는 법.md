## 중요포인트

256 - 75 = 181


256 + (-75) = 181

```
100000000 = 256
-01001011 = 75
----------------
10110101 = 181
```

75의 비트를 반전시키고 여기에 1을 더하면 
10110101 = 181
이 값이 나오게 된다.

```
01001011   ← 75
   ↓ 비트 반전
10110100
   ↓ +1
10110101   ← 75의 2의 보수
```
