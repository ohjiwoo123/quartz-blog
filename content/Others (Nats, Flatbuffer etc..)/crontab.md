**crontab은 “리눅스에서 정해진 시간마다 명령이나 스크립트를 자동으로 실행해주는 예약 실행 도구”**.


### 크론탭 편집
```
crontab -e
```


### 크론탭 확인 
```
crontab -l # 내 크론 목록 보기
crontab -r # 전체 삭제
```

* * * * *
│ │ │ │ │
│ │ │ │ └─ 요일 (0–7, 일요일)
│ │ │ │─── 월 (1–12)
│ │ │───── 일 (1–31)
│ │─────── 시 (0–23)
└───────── 분 (0–59)


### 매분마다 특정 쉘 스크립트 재실행 
```
* * * * * /home/mediastreamingserver/check_alive.sh >> /tmp/check_alive.log 2>&1
```
