### 메모리 구조 그림 

![[Pasted image 20260901232245.png]]


1. STACK - 지역변수와 매개변수가 할당 되는 곳
2. HEAP - 사용자의 동적할당시 할당 되는 곳 
3. DATA - 전역변수 및 정적 변수 선언시 할당 되는 곳
4. CODE - 실행할 프로그램의 코드가 할당 되는 곳 

프로그래밍을 할 때, 항상 내가 선언하는 변수가 어디 메모리에 잡히는지, 생각을 하면서 프로그래밍을 해야한다. 나중에 ADVANCED 한 프로그래밍을 할 때에도 도움이 많이 될 것이다.

이 그림은 다른 곳에서도 자주 쓰이고, 모든 공부에 기본이 되는 그림이다.
std::string이 어떤식으로 할당되는지, class 선언시 어떤식으로 할당 되는지, static이 왜 프로그램 종료까지 소멸되지 않는지에 대한 모든 답이 된다.
